# Learning notes

1. **Agent loop:** The model chooses registered reads/preparations. Harness owns budgets, schema checks, event recording, pausing and errors. Rehearsal replaces only the choice adapter, so business behavior remains identical.
2. **Retrieval:** Scoped approved articles return source IDs and versions. Citations attach to saved chat messages and survive later turns. Retrieved text cannot register tools or change a Java policy.
3. **Action lifecycle:** A persisted proposal is an exact capability bound to one session/conversation. Confirming it rechecks the current resource version under a database lock. A repeated click returns the original receipt.
4. **Unknown is a result:** An after-commit timeout can produce a real business change with an uncertain harness outcome. Keep UNKNOWN visible, block another change and reconcile by stable operation ID. Do not repeat the write or invent success.
5. **Reuse:** Commerce and cleaning supply policies/tools/intake fields; run engine, chat, event viewer and confirmation storage are shared. Domain adapters still require code and tests.
